This article is about the setup of the Bridge router.

# Initial setup

One of the most straightforward experience I had. 
I followed the setup guide in the package leaflet.
Then, I followed the official [docs to set up the WISP mode](https://docs.cudy.com/user_guide/wireless_router/general_settings_wisp/), in which the router act as a wireless to ethernet/wireless bridge.
Technically this mode already does what I need from this router. However, as it will be explained later, I will use OpenWrt, to have more control/features over this bridge functionality.
